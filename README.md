# Blockchain-Demonstratortag 2026

Interaktive 16:9-Präsentation zum Demonstratortag am 25.11.2026 (Blockchain-Schaufensterregion Mittweida).

## Bedienung
- **Weiter:** Leertaste, Pfeil rechts/unten, Bild ab, Enter oder Klick auf die Folie
- **Zurück:** Umschalt+Leertaste, Pfeil links/oben, Bild auf, Rücktaste oder Klick auf den linken Rand
- **Start / Ende:** Pos1 / Ende
- **Vollbild:** Taste F oder das ⛶-Symbol unten
- Auf Touchgeräten: nach links/rechts wischen

## Aufbau
- `index.html` – alle 13 Folien
- `assets/css/styles.css` – Layout, Farben, Animationen
- `assets/js/app.js` – Navigation, Vollbild, Skalierung auf jede Bildschirmgröße
- `assets/img`, `assets/icons` – Bilder und Logos aus den Quellpräsentationen

## Lokal öffnen
`index.html` im Browser öffnen. Kein Build-Schritt nötig.
